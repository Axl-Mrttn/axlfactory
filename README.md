# AXL Factory

> AXL Factory is a space for developing ideas. Small, specific things. Projects that don't need to reach the masses, they just need to exist.

Live at [axlfactory.com](https://axlfactory.com).

## Stack

- Vite
- React 18 + TypeScript
- Tailwind CSS
- shadcn/ui

## Development

Requires Node.js 18+ and npm.

```sh
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

Dev server runs at `http://localhost:8080`.

## Deploy

Hosted on Vercel with automatic deploys from `main`.
